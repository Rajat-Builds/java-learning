## Chapter 8 — Object Oriented Programming (OOP)

### What I learned

**Classes and Objects**
- Class — a blueprint for creating objects
- Object — an instance of a class with its own data
- Constructor — special method that runs when an object is created

**Four Pillars of OOP**
- Encapsulation — hiding data using private variables and public getters/setters
- Inheritance — one class inherits properties and methods from another using `extends`
- Polymorphism — same method behaves differently based on the object
- Abstraction — hiding complex implementation, showing only what is necessary

**Other concepts**
- `this` keyword — refers to the current object
- Method overloading — same method name with different parameters
- Method overriding — child class redefines a method from parent class
- `super` keyword — refers to the parent class

### Key concepts
- OOP makes code organized, reusable, and easier to maintain
- Inheritance reduces code repetition
- Polymorphism makes code flexible and extensible
- Encapsulation protects data from being changed accidentally
- OOP is the foundation of Spring Boot — every class, controller, and service uses it
