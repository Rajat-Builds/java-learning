## Chapter 9 — Collections (ArrayList)

### What I learned
- What ArrayList is and why it is better than a regular array
- ArrayList grows automatically — no need to define size upfront
- Important ArrayList methods:
  - `add()` — adds an item to the list
  - `remove()` — removes an item by index or value
  - `get()` — accesses an item by index
  - `size()` — returns total number of items
  - `contains()` — checks if an item exists in the list
- Storing custom objects in ArrayList — using your own classes as list items

### Key concepts
- ArrayList is part of the `java.util` package — must be imported
- Unlike arrays, ArrayList can hold only objects, not primitives directly
- Use `Integer` instead of `int`, `Double` instead of `double` in ArrayList
